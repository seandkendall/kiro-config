# Session Continuity

## Resuming Work

- At the start of every session, check for existing TODO lists using `todo_list` lookup
- Check for in-progress Kiro Specs (.kiro/specs/) and resume from the current phase
- Review recent file changes to understand where the last session left off
- Resume work from the last known state rather than starting fresh

## Context Preservation

- When ending a session with incomplete work, summarize progress in the TODO list context
- Note any decisions made, blockers encountered, or next steps planned
- Reference specific file paths and line numbers for in-progress changes
